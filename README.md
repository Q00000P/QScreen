# QScreen 📸

Современная кроссплатформенная утилита для создания, аннотирования и мгновенного обмена скриншотами (Windows 11 / macOS).

## Возможности
- 🎯 **Захват области экрана** с субпиксельным Reticle-прицелом и отображением размеров.
- 🔲 **Умный захват окон** с чистым рендерингом без наложения перекрывающих приложений.
- 📜 **Скролл-скриншоты (Scrolling Capture)** и длинные снимки страниц.
- 🎨 **Графический редактор**: Стрелки, рамки, эллипсы, текст, выноски (Speech Bubble), нумерованные шаги, маркер, пикселизация/цензура и линейка в пикселях.
- ✨ **Beautify**: создание градиентных фонов с мягкими тенями.
- 🔍 **Офлайн OCR**: мгновенное распознавание текста без обращения к облачным серверам.
- 🖐 **Нативный Drag & Drop**: перетаскивание скриншотов в Telegram, Discord, Slack, Notion и Проводник.
- 💾 **Экспорт**: PNG, JPG (с настройкой качества) и PDF.

## Горячие клавиши (настраиваемые)
- \Ctrl + Shift + 4\ — Захват области
- \Ctrl + Shift + 6\ — Умный захват (Окно / Зона)
- \Ctrl + Shift + 7\ — Скролл-скриншот
- \Ctrl + Shift + 3\ — Снимок всего экрана
